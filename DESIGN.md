# Upgrade Atlas

## Job

Python maintainers collect primary-source evidence before reviewing a dependency
upgrade. This tool does not edit code, install dependencies or certify an upgrade.

## Treatment

Utilitarian evidence desk. The upgrade pair comes first, the research status
second, and source excerpts third. No landing page or decorative illustration.
The source ledger itself is the visual asset: real title, URL, snippet and search
provenance. Synthetic examples remain explicitly labelled and separate from live
requests.

## Tokens

- Paper: #F5F8F7; dark counterpart #151A19.
- Surface: #FFFFFF; dark counterpart #202725.
- Ink: #18322C; dark counterpart #EDF5F1.
- Secondary ink: #486359; dark counterpart #B7CEC3.
- Action teal: #075D59; dark counterpart #8CD9D0.
- Review red: #9D332C; dark counterpart #FFB4AA.

Type roles: Georgia for the compact product title; system sans-serif for body and
controls; system monospace for version pairs, search IDs and source URLs. All
letter spacing is zero. Body and form controls stay at normal readable sizes.

## Layout

An unframed two-column work surface: fixed research form on the left, flexible
evidence ledger on the right. Mobile collapses into a single column with the form
above the ledger. Entries are flat rows rather than nested cards. A coverage table
answers which searches have target-specific sources; it is not a compatibility
score. Search errors retain explicit partial results.

## Skeleton

1. Compact product header and provider readiness.
2. Labelled package/current/target inputs; research and synthetic-example actions.
3. Evidence status, target-specific coverage and review gaps.
4. Search provenance and source ledger, grouped by purpose.
5. JSON/Markdown export and limitations.

## Originality

This is not a conversational search wrapper. It enforces package-specific primary
source boundaries, matches the requested target version, distinguishes snippets
from inspected documents, and carries search IDs and uncovered questions into an
exportable review packet. A generic answer box was replaced with a review ledger.
